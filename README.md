# OpenGolfSim

**OpenGolfSim** is a modern, open-source golf simulator platform — built for hobbyists, engineers, and pros who want full control over their setup.

🚀 **Features**

- Full-stack simulator engine (launch monitor integration, ball flight physics)
- High-fidelity graphics with real-world course data
- Multiplayer and tournament modes
- Modular plugin system (hardware, swing analysis, AI caddie)
- Web-based dashboard for stats, replays, and swing insights

🛠 **Tech Stack**

- Frontend: React + Three.js
- Backend: Python (Flask/FastAPI) + WebSockets
- Physics Engine: Custom ball-flight physics with real-world validation
- Optional: OpenCV-based club tracking, LIDAR course mapping

💡 **Why OpenGolfSim?**

- No vendor lock-in
- Customize your hardware, ball flight models, and visuals
- Built for extensibility: add your own sensors, analytics, or course packs
